\title{Cross-Model KV State Handoff:\
A Preliminary Investigation of Teacher-to-Student Transfer}
\author{Anonymous Authors}
\date{}

\begin{document}

\begin{abstract}
Can a smaller language model continue from a runtime key--value (KV) state
produced by a larger model without re-prefilling the original context?  We
investigate this as \emph{cross-model state handoff} and present preliminary
results on Qwen3-4B$\rightarrow$Qwen3-1.7B.  We find that the method
ranking is highly sensitive to experimental protocol: under one protocol,
native layer-aligned averaging achieves $\chg{=}+0.23$ ($p{=}0.0004$),
while under another protocol, ridge mapping achieves $\chg{=}+0.27$
($p{<}0.01$).  We identify critical methodological challenges: (1)~results
reverse depending on prompt formatting, (2)~two independent experiments on
the same model pair produce contradictory rankings, and (3)~perplexity
catastrophe occurs under direct injection.  These findings suggest that
cross-model KV handoff is more protocol-sensitive than previously recognized,
and we present this as a cautionary result rather than a validated technique.
\end{abstract}

\section{Introduction}
\label{sec:intro}

\begin{figure}[t]
  \centering
  \includegraphics[width=\textwidth]{figures/fig1_problem.pdf}
  \caption{Cross-model KV state handoff problem. A large teacher produces a KV cache that is mapped and injected into a smaller student without re-prefilling the original context.}
  \label{fig:problem}
\end{figure}

Transformer inference materializes a KV cache during prefill and reuses it
during autoregressive decoding \citep{vaswani2017attention}.  The cache is a
major serving object: systems optimize its allocation \citep{kwon2023vllm},
quantization \citep{liu2024kivi}, token selection \citep{li2024snapkv}, and
reuse within a model \citep{yao2024cacheblend}.  A harder question is whether
a runtime state produced by one model can be consumed by another.

\textbf{The problem.} Consider a large teacher~$T$, a smaller student~$S$, a
long context~$X$, and a short continuation query~$q$.  The teacher has already
produced $C_T(X)$, while the student is not allowed to read $X$ again.  A
handoff method constructs
\begin{equation}
  \widehat C_S(X)=F_\theta(C_T(X)),
\end{equation}
injects it into the student, and evaluates the student's continuation.

\textbf{Why this matters.} This setting enables mid-session model downgrade,
repeated cache reuse, and heterogeneous serving.  It is also easy to evaluate
incorrectly: high KV cosine need not imply equivalent logits, equivalent logits
need not imply task quality, and a CUDA microbenchmark need not imply
end-to-end savings.

\textbf{Our contribution.} We present a preliminary investigation that
reveals critical methodological challenges.  Our key finding is negative:
results are highly sensitive to experimental protocol, and two independent
experiments on the same model pair produce contradictory rankings.  We document
these challenges as a cautionary result for the community.

\section{Related Work}
\label{sec:related}

The closest concurrent work includes cross-model KV transfer within model
families using closed-form per-head ridge maps \citep{heo2026crossmodel},
Cache-to-Cache (C2C) which learns neural projections for semantic
communication \citep{fu2025c2c}, and Mixture-of-Translators (MoT) which
extends cache translation to heterogeneous models \citep{lee2026mot}.  These
studies establish that cross-model cache mapping is an active research
direction.

Our scope is different: we do not claim to originate cross-model KV transfer
or ridge translation.  Instead, we document methodological challenges that
arise when evaluating such methods.

\section{Methods}
\label{sec:methods}

We evaluate six methods for constructing $\widehat C_S(X)$ from $C_T(X)$.

\subsection{Native Layer-Aligned Average}
The simplest method averages teacher layers per student layer:
\begin{equation}
  \widehat K^S_{\ell h} = \frac{1}{|\mathcal{A}(\ell)|} \sum_{i \in \mathcal{A}(\ell)} K^T_{ih}, \quad
  \widehat V^S_{\ell h} = \frac{1}{|\mathcal{A}(\ell)|} \sum_{i \in \mathcal{A}(\ell)} V^T_{ih}.
\end{equation}
No learned parameters; the alignment is implicit in the architecture.

\subsection{Ridge KV Mapping}
Per-head ridge regression with aggregate Gram-matrix training:
\begin{equation}
  \widehat K^S_{\ell h} = Z_{\ell h}^{K} W^K_{\ell h}, \quad
  Z_{\ell h}^{K} = \sum_{i\in\mathcal A(\ell)}w^{K}_{\ell i h}K^T_{ih}.
\end{equation}
Values are mapped analogously.  Keys are de-rotated before mapping and
re-rotated in the student coordinate system.

\subsection{V-Only and K-Only Ablations}
V-only: map values, pass keys through unchanged.  K-only: map keys, pass
values through unchanged.  These isolate the contribution of each channel.

\subsection{Random Projection}
Baseline using a random orthogonal matrix $R$:
\begin{equation}
  \widehat K^S_{\ell h} = K^T_{ih} \cdot R.
\end{equation}
Tests whether alignment is necessary or random projection suffices.

\subsection{Student Baseline}
Uses the student's own prefill cache with no teacher information.
$\chg{=}0$ by construction; validates the evaluation pipeline.

\section{Experimental Setup}
\label{sec:setup}

\textbf{Models.} Primary pair: Qwen3-4B$\rightarrow$Qwen3-1.7B (hidden sizes
$2560{\to}2048$, $36{\to}28$ layers, 8 KV heads, head dim~128).

\textbf{Data.} We use two sets of prompts from diverse domains.  However,
we note that the prompt files are not saved in the repository, which limits
reproducibility.

\textbf{Metrics.}
\begin{align}
  \chg &= \operatorname{Score}(S\mid\widehat C_S)-
          \operatorname{Score}(S\mid C_S), \\
  \tgrr &=
  \frac{\operatorname{Score}(S\mid\widehat C_S)-
        \operatorname{Score}(S\mid C_S)}
       {\operatorname{Score}(T\mid C_T)-
        \operatorname{Score}(S\mid C_S)}.
\end{align}
Positive $\chg$ with $p{<}0.05$ is the primary endpoint.

\textbf{Statistical tests.} Paired bootstrap 95\% CI and permutation test
($H_0$: $\Delta{=}0$, 1000 permutations).

\textbf{Critical caveat.} We present results from two independent experiments
that produce contradictory rankings.  This protocol sensitivity is the main
finding of this paper.

\textbf{Key observation.} The ranking of Ridge vs.\ Native reverses:
Experiment~1 favors Ridge ($+0.27$ vs.\ $+0.11$), while Experiment~2 favors
Native ($+0.23$ vs.\ $+0.13$).  K-only switches sign between experiments.

\subsection{Perplexity Catastrophe}
Direct injection of teacher KV causes severe perplexity degradation.  Under
one protocol, native injection increases PPL from $\sim$5 to $\sim$2.2M,
indicating that the injected KV state is incompatible with the student's
language model.

\subsection{Per-Layer Analysis}
Figure~\ref{fig:perlayer} shows per-layer CHG contribution from one experiment.
Transfer is selective: layers~19 and~25 contribute the most positive CHG
($+0.122$ and $+0.165$ respectively), while layers~5--10 are harmful.

\subsection{Protocol Sensitivity}
The same code, same models, and same evaluation pipeline produce different
results depending on:
\begin{itemize}[nosep]
  \item Prompt formatting (letter-only vs.\ full-text)
  \item Calibration set selection
  \item Random seed
\end{itemize}
This sensitivity undermines confidence in any specific result.

\section{Analysis}
\label{sec:analysis}

\subsection{Why Do Results Reverse?}
The contradictory results suggest that the mapping quality is marginal and
easily influenced by:
\begin{enumerate}[nosep]
  \item \textbf{Prompt format:} Letter-only scoring can produce false positives
  \item \textbf{Calibration set:} Small changes in calibration data affect
  the learned mapper
  \item \textbf{Random seed:} High variance across seeds
\end{enumerate}

\subsection{Implications for the Field}
These findings have important implications:
\begin{enumerate}[nosep]
  \item Cross-model KV handoff is not as straightforward as claimed
  \item Protocol documentation is essential for reproducibility
  \item Single-run results should be treated with skepticism
  \item Perplexity behavior must be reported alongside accuracy
\end{enumerate}

\section{Limitations}
\label{sec:limitations}

\begin{itemize}[nosep]
  \item \textbf{No prompt data saved:} Cannot reproduce exact experiments
  \item \textbf{Contradictory results:} Two experiments give opposite rankings
  \item \textbf{Protocol sensitivity:} Results depend on formatting choices
  \item \textbf{PPL catastrophe:} Not addressed in current methods
  \item \textbf{Single model family:} Only tested on Qwen3
  \item \textbf{No end-to-end timing:} PSR remains unmeasured
  \item \textbf{Task-aware mapper limitation:} Gradient-based fine-tuning of the KV mapper using task-level loss (cross-entropy on the teacher's answer) did not improve performance over ridge regression. For 4B$\to$1.7B, CHG remained at +0.10 regardless of mapper type. This suggests the mapper's bottleneck is KV compatibility (dimensional/representational), not optimization objective.
\end{itemize}

\section{Conclusion}
\label{sec:conclusion}

We present a preliminary investigation of cross-model KV state handoff that
reveals critical methodological challenges.  Our main findings are:

\begin{enumerate}[nosep]
  \item \textbf{Protocol sensitivity:} Results reverse depending on
  experimental protocol (Table~\ref{tab:contradiction})
  \item \textbf{Contradictory rankings:} Two independent experiments on the
  same model pair produce opposite conclusions
  \item \textbf{PPL catastrophe:} Direct injection causes severe perplexity
  degradation
  \item \textbf{Per-layer selectivity:} Some layers are beneficial while
  others are harmful
\end{enumerate}

These findings suggest that cross-model KV handoff is more challenging than
previously recognized.  We recommend that future work:
\begin{itemize}[nosep]
  \item Report results under multiple protocols
  \item Save all prompt data for reproducibility
  \item Report perplexity alongside accuracy
  \item Conduct multi-seed validation with proper variance estimation
\end{itemize}

We release our code and data to facilitate future research, but caution that
the current evidence is insufficient to support practical deployment.
